# cyberdrk.github.io

Personal portfolio of **Dipti R. Kulkarni**: https://cyberdrk.github.io

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme, deployed automatically to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Where things live

| What                           | File                                                                    |
| ------------------------------ | ----------------------------------------------------------------------- |
| Home / about page              | `_pages/about.md`                                                       |
| CV page content                | `_data/cv.yml`                                                          |
| Tech background page           | `_pages/tech.md`                                                        |
| Social links                   | `_data/socials.yml`                                                     |
| GitHub repos shown             | `_data/repositories.yml`                                                |
| Site name, description, colors | `_config.yml`, `_sass/_themes.scss`                                     |
| Profile photo                  | `assets/img/prof_pic.jpg` (then enable `profile:` in `_pages/about.md`) |
